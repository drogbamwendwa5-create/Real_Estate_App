# HomeNest - Real Estate App

A modern real estate platform for buying, selling, and renting properties.

## Features
- Property listings with detailed information
- User authentication and profiles
- Favorites and saved searches
- In-app messaging
- Map view of properties
- Role-based dashboards
- AI-powered assistance

## Design
HomeNest features a sophisticated UI with:
- Deep blue primary color conveying trust and stability
- Emerald green accents for call-to-action elements
- Clean typography with clear hierarchy
- Responsive design that adapts to different screen sizes
- Smooth animations and micro-interactions

## Getting Started
1. Install dependencies: `npm install`
2. Start the development server: `npm start`
3. Scan the QR code with Expo Go app

## Theme Customization
The app uses a centralized theme system in `Frontend/theme/index.js` that supports both light and dark modes.
